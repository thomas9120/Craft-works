Portable only. This catalog lists ZIP, DMG, AppImage and tar.gz builds. Platform installers (.msi, .deb, .rpm, .flatpak, .pkg.tar.zst) and the -cli / -server / -web side builds are left out on purpose. Uninstall support is not part of this version.

Versions and links come from the public GitHub Releases API api.github.com. Every release is re-checked automatically every 6 hours and published with this page; Refresh asks GitHub directly from your browser. GitHub allows 60 unauthenticated requests an hour per network and a full refresh uses 13, so when that runs low the apps checked longest ago go first.
